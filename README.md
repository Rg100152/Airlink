# ✈️ AIRLINK - Fly Across Incredible India

A modern, responsive flight booking website designed for domestic air travel in India. Built with pure HTML, CSS, and JavaScript, this project simulates a complete airline booking experience from search to payment.

![AIRLINK Banner](images/airline-hero.jpg)

## 🌟 Features

### User-Facing Pages
- **Homepage (`index.html`)**: Hero section with flight search box and popular domestic routes.
- **Flight Search (`flights.html`)**: Browse available flights with filters, sorting, and airline details.
- **Booking (`booking.html`)**: Enter passenger details with a live flight summary sidebar.
- **Payment Gateway (`payment.html`)**: Multiple payment options (Card, Net Banking, UPI, Wallets).
- **Net Banking (`netbanking.html`)**: Bank selection and secure login simulation.
- **UPI Payment (`upi.html`)**: UPI app selection, QR code simulation, and live countdown timer.
- **Confirmation (`confirmation.html`)**: Booking confirmation with PNR, flight details, and e-ticket download.
- **Destinations (`Destinations.html`)**: Explore Indian destinations with interactive category filters.
- **Offers (`Offers.html`)**: Flight discounts and bank partnership offers.
- **About Us (`about.html`)**: Company story, mission, vision, and leadership team.
- **Support (`Support.html`)**: Contact cards, support ticket form, and interactive FAQ accordion.
- **Sign In (`Sign In.html`)**: Secure login form with password toggle and social login options.

### Design Highlights
- 🇮🇳 **Indian Aviation Theme**: Deep Navy Blue, Saffron, White, and Green color palette.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.
- ✨ **Modern UI/UX**: Clean layouts, smooth transitions, and interactive elements.
- 🎨 **CSS Variables**: Consistent theming across all pages.
- ⚡ **Interactive JavaScript**: FAQ accordions, payment method toggles, filters, and live timers.

## 🛠️ Tech Stack

- **HTML5**: Semantic markup for all pages.
- **CSS3**: Custom styling with Flexbox and CSS Grid.
- **JavaScript (ES6)**: Interactive features and DOM manipulation.
- **TypeScript**: Type-safe scripting (`script.ts`).
- **Font Awesome 6**: Icons for UI elements.
- **Google Fonts (Poppins)**: Modern typography.
